# GLEBA

The Gleba system tracks statistics and metrics associated with the data processed throughout the Nexus pipeline.

## Overview

As data is processed, Gleba generates metrics to help identify patterns and trends. These statistics are useful for data analysis, as well as for operational purposes such as billing based on the volume of new data added by different organizations.

## Key Functionalities

* **Metric Generation:** Creates metrics about the data to facilitate pattern discovery.
* **Statistics Tracking:** Maintains counts and associations, such as the number of citations per journal article.
* **Operational Analytics:** Provides data that can be used for billing and monitoring data ingestion volumes.
* **Data Staleness Monitoring:** Addresses the issue of aging/stale statistics to ensure metrics remain accurate as data is updated.
