# POMUS

Pomus is the frontend application designed to present and visualize the data output from the Aquilo and Nexus systems.

## Overview

Pomus provides a user interface for browsing and exploring the high-quality, enriched data produced by the Nexus pipeline. It is built with a focus on being "HTML first," prioritizing speed and simplicity.

## Key Functionalities

* **Data Visualization:** Displays processed datasets from Aquilo and relationship metadata from Nexus.
* **Server-Side Rendering:** Uses a minimalist, server-side approach to deliver content efficiently.
* **Modern Web Tech:** Employs Pico CSS for lightweight styling and HTMX to handle API requests without complex client-side JavaScript.
